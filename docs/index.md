## 📖 Documentation Formats

### Online Reading
All documentation is written in Markdown and can be read directly on GitHub or in any Markdown viewer.

### Local Setup
```bash
# Clone repository
git clone https://github.com/dimmastro/openastro2.git
cd openastro2

# View documentation
cd docs
# Open any .md file in your preferred editor
```

### Documentation Tools
```bash
# Generate HTML documentation (if using MkDocs)
pip install mkdocs mkdocs-material
mkdocs serve

# Generate PDF documentation (if needed)
pip install md-to-pdf
md-to-pdf README.md
```
